# Data folder

The source dataset (`Bisoprolol_icsr_sample_1068rows.xlsx`) is intentionally
excluded from this submission per the Submission Guide's instruction not to
re-include it, since the reviewers already have it.

To run this project, place the original file at:
`data/Bisoprolol_icsr_sample_1068rows.xlsx`

All paths in `analysis/load_data.py` are relative to the project root and
will pick it up automatically once it's placed here.
